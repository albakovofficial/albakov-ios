# Большое обновление приложения ALBAKOV

Список того, что делаем. 12.11.2026, 23:30: сайт выпущен (13.63.1, PR #44), приложение — 2.1.3 в TestFlight.

Последняя выгруженная сборка: **1.0.2 (97)** в TestFlight, 16.11 утром. В App Store для всех — **1.0.1 (69)**. Сайт — **13.65.3** (PR #61).

## Общее правило этого обновления
- Сайт и приложение выглядят одинаково: всё утверждённое (палитра по разделам, меню ☰, панель управления, раздел «Детям», личный кабинет) делаем и там, и там
- Палитру разделов (бордо / чёрный / небесный) применяем везде, где можно, во всех разделах сайта и приложения: кнопки, выделение, переключатели, счётчики, акценты; оранжевый `#ff5a3c` убираем отовсюду (точки в заголовках, метки, свечения)

## Правила
- **Версии — при каждом обновлении** (владелец 12.11): приложение 2.1.1 → 2.1.2 → … → 2.1.9 → 2.2.0 (после девятки — следующая цифра слева); сайт так же: 13.63.1 → … → 13.63.9 → 13.64.0. Когда приложение выйдет в App Store для всех, первая версия там — **1.0.0**.
- Загрузка на GitHub, сборка и TestFlight — только когда владелец скажет.
- Сайт: выпуск только после «запускай»; в `release` ничего без слова владельца.
- Сайт: перед каждым выпуском `npm run build` в albakov-shop (уменьшенные скрипты и стили; без этого сайт отдаёт обычные файлы). Сервер — ядро `server.js` + модули `lib/app/` (16.11).
- Пароли и ключи вводит только владелец.
- Коммиты — на русском, без строк `Claude-Session` и `Co-Authored-By`.
